## 2. Подключение данных

### Задание 1. Загрузка и подготовка

1. Загрузите CSV-файл в Tableau Public через экран подключения.
2. Проверьте типы полей: измерения (Dimensions) и меры (Measures) должны распознаваться автоматически.
3. Присвойте полю `Store и Holiday_Flag` тип «строка» (измерение), полям `Weekly_Sales`, `Temperature`, `Temperature` и др. — числовые меры.
4. Создайте вычисляемые поля (Create Calculated Field):
   - `Target Level`: IF([popularity] >= 75, 'Very high', IF([popularity] >= 50, 'High', IF([popularity] >= 25, 'Medium', IF([popularity] >= 10, 'Low', 'Very low'))))
   - `X Norm`: [duration_ms] / 60000
   - `Balance`: ROUND([valence] - [speechiness], 2)
   - `Composite Index`: ROUND(([energy] * 0.4) + ([danceability] * 0.3) + ([valence] * 0.3), 2)

5. Создайте вычисляемое поле `Country` — ключ связи со стандартными геодатасетами (наборы 2–4) для геовизуализации и группировки по континентам. Если в основном датасете уже есть поле страны (`country`, `Country`, `region`, `state`) — создайте `Country` как копию с нормализацией: `Country = UPPER(TRIM([country]))`. Если географического поля нет — создайте вычисляемое поле, извлекая страну из адреса/города, либо присвойте константу страны источника данных по умолчанию (например, для California Housing — `"United States"`, для Airbnb NYC — `"United States"`), обязательно обосновав выбор в отчёте. После создания поля `Country` добавьте подключение наборов 2–4 через **Connect → To a File → Text File** и настройте связи (Relationships) или Data Blending по полю `Country` = `name` (набор 2), затем `country-code` (наборы 3–4).
